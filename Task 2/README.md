# Task 02 – Data Types and Meter Rollover

## Files
- `task02.c` – C implementation and required demonstrations.
- `analysis.md` – data type selection, limits, money precision, rollover explanation and complexity/assumptions.
- `run_output.txt` – captured output from the test run in the build environment.
- `compile.log` – compiler command and build result.

## Compile
From the assignment root folder:

```sh
gcc -Wall -Wextra -std=c11 Task02/task02.c -o Task02/task02
```

## Run

```sh
./Task02/task02
```

On Windows/MSYS2, run `Task02/task02.exe` after compiling with `-o Task02/task02.exe`.

## Important
`sizeof(long)` and other implementation-dependent type sizes may differ between systems. The recorded output is from the environment used to compile this package. Recompile on the college/own system and keep that system's actual output as submission evidence.
